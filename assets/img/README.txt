Put your own images here (profile photo, project covers, blog covers).

Then reference them from the content files, e.g. in content/site.js:
    avatar: "assets/img/manish.jpg"
    projects: [ { ..., image: "assets/img/trail.png" } ]
and in content/posts.js:
    cover: "assets/img/my-post-cover.jpg"

Until then the site uses the default avatar silhouette and picsum.photos
placeholder images.
